# 07 — Status-first Task View

**What to build:** A dedicated Task View that presents Progress File Tasks by explicit Task Status, with task details, dependencies, and Current Task emphasis.

**Blocked by:** 06 — Load and remember Progress File.

**Status:** ready-for-agent

- [ ] Successful loading opens Task View; `d` and `t` switch between Dashboard and Task View.
- [ ] Default order is blocked, in-progress, awaiting-review, todo, done with canonical Status Labels.
- [ ] Task details show only supplied project data, including dependency statuses and verification information when present.
- [ ] Current Task is highlighted when visible; a notice identifies when filters hide it.
- [ ] Task View contains no News Feed and uses only its compact clock/date/weather top bar.
